Умножение и деление с числами 0 и 1: математика, 3 класс

Коротко о теме

Ноль и единица — особые числа. С ними ответ в умножении и делении находят без счёта. Умножение на 1 и деление на 1 не меняют число: 5 · 1 = 5, 5 : 1 = 5. Число, разделённое на само себя, равно единице: 5 : 5 = 1. Умножение на ноль даёт ноль: 5 · 0 = 0. Ноль, разделённый на число, тоже равен нулю: 0 : 5 = 0. А на ноль делить нельзя.

Чему научимся

  • умножать на 1 и на 0;
  • делить на 1 и делить число на само себя;
  • делить ноль на число;
  • понимать, почему на ноль делить нельзя;
  • не путать записи 0 · 5, 0 : 5 и 5 : 0;
  • находить неизвестное число в записях с 0 и 1.

Родителям

  • Начните с коробок. Возьмите 5 конфет или пуговиц и 5 коробочек. Подойдут чашки или формочки. Разыграйте с ребёнком все случаи из статьи. Задавайте вопросы по очереди. «Сколько конфет в пяти пустых коробках?» «Как разложить 5 конфет в 5 коробок поровну?» «А если коробок нет?»
  • Правила умножения на 0 и на 1 ребёнок учил во 2 классе. Теперь к ним добавляется деление. Если умножение забылось, начните с него.
  • Просите читать каждую запись вслух. Если ребёнок слышит «разделить на ноль», пусть говорит «стоп». Это главный приём темы.
  • Поиграйте в карточки. Напишите на них 8 записей: 0 · 6, 6 · 0, 1 · 6, 6 · 1, 6 : 1, 6 : 6, 0 : 6, 6 : 0. Ребёнок раскладывает карточки на четыре кучки: «0», «1», «6» и «стоп». Потом возьмите другое число вместо 6, например 9.
  • Следите, не путает ли ребёнок умножение со сложением, а деление с вычитанием. Частые ошибки: 7 · 0 = 7, 9 · 1 = 10, 6 : 6 = 0. Спросите: «Это умножение или сложение? Покажи на коробках».
  • Дайте ребёнку калькулятор в телефоне. Пусть разделит 5 на 0. Посмотрите вместе, что он покажет, и обсудите почему.

Умножаем: конфеты в коробках

Умножение — это сложение одинаковых чисел. Запись 4 · 5 значит: 4 взять 5 раз. Например, 5 коробок, в каждой по 4 конфеты: 4 + 4 + 4 + 4 + 4 = 20. Числа, которые умножают, называются множителями. Ответ называется произведением. Первый множитель — сколько конфет в одной коробке. Второй — сколько коробок.

Теперь посмотрим, что будет с единицей и нулём.

  1. Единица умножается на число. 5 коробок, в каждой по 1 конфете. Всего 1 · 5 = 1 + 1 + 1 + 1 + 1 = 5 конфет.
  2. Число умножается на единицу. Одна коробка, в ней 5 конфет. Складывать здесь нечего. Это 5 взять один раз: 5 · 1 = 5.
  3. Ноль умножается на число. 5 пустых коробок, в каждой 0 конфет. Всего 0 · 5 = 0 + 0 + 0 + 0 + 0 = 0. Сколько ни бери пустых коробок, конфет не прибавится.
  4. Число умножается на ноль. Коробок с 5 конфетами нет ни одной. Это 5 взять ноль раз: 5 · 0 = 0. Есть и другой способ. От перестановки множителей произведение не меняется. Поэтому 5 · 0 = 0 · 5 = 0.

Получились два правила:

  • если один из множителей равен 1, произведение равно другому множителю: 1 · 5 = 5, 5 · 1 = 5;
  • если один из множителей равен 0, произведение равно нулю: 0 · 5 = 0, 5 · 0 = 0.

Правила можно записать коротко, с буквой: a · 1 = a, 1 · a = a, a · 0 = 0, 0 · a = 0. Буква a обозначает любое число.

Делим: раскладываем конфеты поровну

Деление — это раскладывание поровну. Запись 10 : 5 значит: 10 конфет разложили в 5 коробок поровну. В каждой коробке окажется по 2 конфеты. Число, которое делят, называется делимым. Число, на которое делят, — делителем. Ответ — частным.

Деление проверяют умножением. Частное умножают на делитель, должно получиться делимое. Например, 10 : 5 = 2, потому что 2 · 5 = 10.

  1. Деление на единицу. 5 конфет кладём в 1 коробку. Все 5 конфет окажутся в ней: 5 : 1 = 5. Проверка: 5 · 1 = 5.
  2. Деление числа на само себя. 5 конфет раскладываем в 5 коробок поровну. В каждой будет по 1 конфете: 5 : 5 = 1. Проверка: 1 · 5 = 5.
  3. Деление нуля на число. Конфет нет, а коробок 5. В каждой коробке будет 0 конфет: 0 : 5 = 0. Проверка: 0 · 5 = 0.

Коротко, с буквой:

  • a : 1 = a — для любого числа;
  • a : a = 1 — для любого числа, кроме нуля;
  • 0 : a = 0 — для любого числа, кроме нуля.

Почему «кроме нуля»? Потому что на ноль делить нельзя. Объясним почему.

Почему на ноль делить нельзя

Попробуем разложить 5 конфет в 0 коробок. Коробок нет, конфеты класть некуда. На вопрос «Сколько конфет в каждой коробке?» ответа нет.

Теперь проверим умножением. Допустим, 5 : 0 равно какому-то числу. Тогда это число, умноженное на 0, должно дать 5. Пробуем разные числа:

  1. 1 · 0 = 0, а не 5.
  2. 2 · 0 = 0, а не 5.
  3. 100 · 0 = 0, а не 5.

Любое число, умноженное на 0, даёт 0. Получить 5 не выйдет. Значит, у записи 5 : 0 нет ответа. Поэтому говорят: на ноль делить нельзя.

А если ноль разделить на ноль? Ищем число, которое при умножении на 0 даёт 0. Подходит любое: 3 · 0 = 0, 7 · 0 = 0. Но ответ у примера должен быть один. Выбрать одно число из всех невозможно. Поэтому и ноль на ноль делить нельзя.

Как не путать 0 · 5, 0 : 5 и 5 : 0

Записи похожи, но ответы у них разные. Поможет приём «Читаю вслух».

  1. Прочитайте запись вслух.
  2. Слышите «умножить» и в записи есть ноль — ответ 0. Неважно, где стоит ноль: 0 · 5 = 0 и 5 · 0 = 0.
  3. Слышите «…разделить на ноль» — стоп. Запись 5 : 0 вычислить нельзя. Конфеты есть, а коробок нет. Запись 0 : 0 — тоже стоп.
  4. Слышите «ноль разделить на» другое число — ответ ноль: 0 : 5 = 0. Конфет нет, все коробки пустые.

Короткая подсказка: «Ноль делить можно, на ноль — нельзя».

Все случаи с коробками в одной таблице:

Запись Конфеты и коробки Ответ
1 · 5 5 коробок по 1 конфете 5
5 · 1 1 коробка с 5 конфетами 5
0 · 5 5 пустых коробок 0
5 · 0 ни одной коробки с 5 конфетами 0
5 : 1 5 конфет в 1 коробку 5
5 : 5 5 конфет в 5 коробок поровну 1
0 : 5 0 конфет в 5 коробок 0
5 : 0 5 конфет, а коробок нет нельзя

Эти правила пригодятся в следующих темах. В умножении столбиком встретится 0 · 3 = 0, в делении уголком — 0 : 4 = 0.

Запомните. Умножение на 1 и деление на 1 не меняют число. Число, разделённое на само себя, равно 1. Если один из множителей равен 0, произведение равно 0. Ноль, разделённый на число, равен 0. На ноль делить нельзя. Ноль делить можно, на ноль — нельзя.

Разбираем на примере

Пример 1. Вычислим 0 · 8 и 8 · 0.

  1. Читаем вслух: «ноль умножить на восемь». Это 8 пустых коробок.
  2. Складываем: 0 + 0 + 0 + 0 + 0 + 0 + 0 + 0 = 0. Значит, 0 · 8 = 0.
  3. Читаем вторую запись: «восемь умножить на ноль». Здесь множители переставлены.
  4. От перестановки множителей произведение не меняется: 8 · 0 = 0.

Ответ: 0 · 8 = 0, 8 · 0 = 0.

Пример 2. Вычислим 0 : 8 и 8 : 0.

  1. Читаем вслух: «ноль разделить на восемь». Ноль делить можно.
  2. Ноль конфет раскладываем в 8 коробок. В каждой 0 конфет: 0 : 8 = 0.
  3. Проверка: 0 · 8 = 0. Верно.
  4. Читаем вторую запись: «восемь разделить на ноль». Слышим «на ноль» — стоп.
  5. Число, которое при умножении на 0 даёт 8, найти нельзя. Такого числа нет.

Ответ: 0 : 8 = 0, а 8 : 0 вычислить нельзя.

Пример 3. Найдём неизвестное число. Буквой x (читается «икс») обозначают число, которое нужно найти.

Запись x · 1 = 14:

  1. При умножении на 1 число не меняется.
  2. Значит, x = 14.
  3. Проверка: 14 · 1 = 14. Верно.

Запись 25 : x = 1:

  1. Частное равно 1. Так бывает, когда число делят на само себя.
  2. Значит, x = 25.
  3. Проверка: 25 : 25 = 1. Верно.

Пример 4. Задача. Шесть друзей поровну разделили 6 яблок. Сколько яблок досталось каждому?

  1. Делим поровну, значит, нужно деление: 6 : 6.
  2. Число делим на само себя, получается единица: 6 : 6 = 1.
  3. Проверка: 1 · 6 = 6. Это все яблоки.

Ответ: каждому досталось 1 яблоко.

Попробуйте сами

Задание 1. Вычислите: 1 · 8, 46 · 1, 0 · 6, 23 · 0, 1 · 1, 0 · 1.

Показать ответ

1 · 8 = 8; 46 · 1 = 46; 0 · 6 = 0; 23 · 0 = 0; 1 · 1 = 1; 0 · 1 = 0.

Задание 2. Вычислите: 37 : 1, 15 : 15, 0 : 4, 72 : 72, 0 : 60, 1 : 1.

Показать ответ

37 : 1 = 37; 15 : 15 = 1; 0 : 4 = 0; 72 : 72 = 1; 0 : 60 = 0; 1 : 1 = 1.

Задание 3. Найдите записи, в которых делят на ноль. Остальные вычислите: 31 : 0, 0 : 31, 0 · 31, 54 : 0, 0 : 54, 54 · 0.

Показать ответ

На ноль делят в записях 31 : 0 и 54 : 0. Так делить нельзя. Остальные: 0 : 31 = 0; 0 · 31 = 0; 0 : 54 = 0; 54 · 0 = 0.

Задание 4. Найдите x и сделайте проверку: x · 1 = 27; 53 : x = 1; 18 : x = 18; x : 1 = 57.

Показать ответ

x · 1 = 27, x = 27. Проверка: 27 · 1 = 27. 53 : x = 1, x = 53. Проверка: 53 : 53 = 1. 18 : x = 18, x = 1. Проверка: 18 : 1 = 18. x : 1 = 57, x = 57. Проверка: 57 : 1 = 57.

Задание 5. Значение выражения — это ответ, который получится при вычислении. Расставьте выражения по порядку: от меньшего значения к большему. 70 : 1, 0 · 35, 26 : 26, 9 · 1, 1 · 41.

Показать ответ

Значения: 70 : 1 = 70; 0 · 35 = 0; 26 : 26 = 1; 9 · 1 = 9; 1 · 41 = 41. Порядок: 0 · 35, 26 : 26, 9 · 1, 1 · 41, 70 : 1.

Задание 6. Найдите ошибки и исправьте их: 8 · 0 = 8; 0 : 3 = 0; 6 : 6 = 0; 7 : 0 = 0; 1 · 9 = 9.

Показать ответ

Ошибки в трёх записях. Верно: 8 · 0 = 0, а не 8. Верно: 6 : 6 = 1, а не 0. Запись 7 : 0 вычислить нельзя: на ноль не делят. Записи 0 : 3 = 0 и 1 · 9 = 9 верные.

Задание 7. В классе 26 учеников. Учитель дал каждому по одной тетради. Сколько тетрадей он раздал?

Показать ответ

1 · 26 = 26. Учитель раздал 26 тетрадей.

Частая ошибка

Путают умножение со сложением. Ребёнок пишет 7 · 0 = 7. Так получается при сложении: 7 + 0 = 7. А при умножении на 0 выходит ноль: 7 · 0 = 0. Похожая ошибка: 9 · 1 = 10. Это ответ для 9 + 1, а 9 · 1 = 9. Ещё одна: 0 · 3 = 3. Верно: 0 · 3 = 0, ведь три пустые коробки — это 0 конфет. Эта ошибка встречается и при умножении в столбик.

Путают деление с вычитанием. Ребёнок пишет 6 : 6 = 0. Так получается при вычитании: 6 − 6 = 0. А 6 конфет в 6 коробок — по одной: 6 : 6 = 1.

Сравните, чтобы не путать:

Действие С нулём С единицей
Сложение 7 + 0 = 7 7 + 1 = 8
Вычитание 7 − 0 = 7 7 − 1 = 6
Умножение 7 · 0 = 0 7 · 1 = 7
Деление 7 : 0 — нельзя 7 : 1 = 7

Делят на ноль. Ребёнок пишет 5 : 0 = 0, как при умножении 5 · 0 = 0. Или пишет 5 : 0 = 5. Обе записи неверные. Это покажет проверка умножением: 0 · 0 = 0 и 5 · 0 = 0, а не 5. На ноль делить нельзя.

Боятся делить ноль. Ребёнок видит ноль и пишет «нельзя» для 0 : 5. Но ноль делить можно: 0 : 5 = 0. Проверка: 0 · 5 = 0. Прочитайте запись вслух. «Разделить на ноль» — нельзя, «ноль разделить на…» — можно.

Проверьте себя

Выберите ответ. Если ошибётесь, появится подсказка.

1Сколько будет 7 · 0?

если один из множителей равен 0, произведение равно 0. Ответ 7 получается при сложении 7 + 0. «Нельзя» бывает только при делении на ноль, а здесь умножение.

2Сколько будет 9 : 9?

число, разделённое на само себя, равно 1. 9 конфет в 9 коробок — по одной. Ответ 0 получается при вычитании 9 − 9, а ответ 9 — при делении на 1.

3Какая запись верна?

ноль делить можно, ответ 0. Проверка: 0 · 6 = 0. В записи 6 : 0 делят на ноль, а так нельзя. Запись 0 : 6 = 6 неверна: 6 · 6 = 36, а не 0.

4Чему равен x в записи x · 1 = 38?

при умножении на 1 число не меняется, поэтому x = 38. Проверка: 38 · 1 = 38. Ответ 39 получится, если спутать умножение со сложением. Ответ 1 неверен: 1 · 1 = 1, а не 38.

5У какого выражения самое большое значение?

50 · 0 = 0, 50 : 50 = 1, 50 : 1 = 50. Самое большое значение — 50.
